Install with one command

Open PowerShell, paste, press Enter. The app downloads to your desktop and starts right away.

Windows PowerShell
PS> irm https://github.com/aquaxs1/Explorer-Manager/releases/download/manager/ExplorerManager-v1.1.exe -OutFile "$env:USERPROFILE\Desktop\ExplorerManager.exe"; & "$env:USERPROFILE\Desktop\ExplorerManager.exe"

No Python required. Prefer clicking? Download from the release page.

Windows PowerShell
PS> git clone https://github.com/aquaxs1/Explorer-Manager.git; cd Explorer-Manager; pip install watchdog customtkinter; python main.py

Needs Python 3.10+ and git on your PATH.

Everything it does

Six things, done properly. No cloud, no subscription, no telemetry.

Real-time watching

A file lands in your Downloads folder and is gone within a second — moved, not copied, no scan schedule.

Rules that stack

Match on a filename keyword, a file extension, or both. Rules run top to bottom — the first match wins.

Many folders at once

Watch Downloads, Desktop and a network share in parallel. Toggle each source on or off without deleting it.

Silent autostart

One click registers Explorer Manager with Windows. It boots hidden and sorts without ever showing a window.

40+ file types

Documents, archives, media, images, code and installers are preselected — or leave the type open for everything.

Clean, modern UI

A tidy desktop app instead of a config file. Your rules are stored in AppData and reload on every start.

Things Windows simply can't do

File Explorer sorts what is already there. Explorer Manager decides where things go in the first place.

Without Explorer Manager

  • Every download lands in one folder and stays there until you clean up by hand.
  • No way to route files by a keyword in the name — Explorer has no rule engine.
  • Same name twice means an overwrite dialog that stops everything.
  • Scripts and scheduled tasks only run on a timer, minutes after the fact.

With Explorer Manager

  • Files are filed the moment they arrive — including drag & drop and renames.
  • "Invoice" goes to your invoice folder, ".mkv" to your media drive. Both at once.
  • Name collisions get numbered automatically — nothing is ever overwritten.
  • Runs from Windows startup, invisible, across every folder you added.

Set up in four steps

Takes about a minute. No config files to edit.

Add a source

Click + Add Source and pick the folder to watch, e.g. your Downloads folder.

Create a rule

Set a filename keyword, a file type, or both — then choose the destination folder.

Save & restart

Save & Restart stores your rules and restarts the watchers immediately.

Turn on autostart

Hit Autostart ON so it launches hidden with Windows and keeps sorting.

Stop tidying your Downloads folder

Set your rules once and let Explorer Manager handle the rest — quietly, in the background, forever.
