Set up in four steps

Takes about a minute. No config files to edit.

Add a source

Click + Add Source and pick the folder to watch, e.g. your Downloads folder.

Create a rule

Set a filename keyword, a file type, or both — then choose the destination folder.

Save & restart

Save & Restart stores your rules and starts sorting. Sort existing files cleans up the old pile.

Turn on autostart

Switch Autostart: OFF to ON so it launches hidden with Windows and keeps sorting.
