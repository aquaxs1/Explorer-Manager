# Explorer Manager 🗂️

**Automated File Organization with a sleek GUI and silent background monitoring.**

Explorer Manager monitors your folders in real-time and moves files automatically based on custom rules.

## ✨ Key Features
* **Real-time Monitoring:** Instantly detects new files.
* **Smart Rules:** Filter by keywords and specific extensions.
* **Modern UI:** Built with CustomTkinter for a professional look.
* **Silent Mode:** Automatically starts with Windows and runs hidden.
